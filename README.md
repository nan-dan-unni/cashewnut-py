# Cashewnut 🥜

**Cashewnut** is a Python framework for building server-side applications, built around a rich, hierarchical middleware system and an inbuilt AI architecture.

> ⚠️ **Work in progress**
>
> Cashewnut is currently under active development and is **not ready for use**. APIs, architecture, and features may change significantly.

## Status

🚧 Early development

## Vision

Cashewnut aims to provide a structured foundation for building modern server-side applications with:

- Hierarchical middleware
- Built-in AI architecture
- Extensible application components
- A clean, developer-friendly Python API

More documentation and examples will be added as the framework matures.

**Do not use Cashewnut in production yet.**
